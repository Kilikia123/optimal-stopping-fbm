# 1. Постановка задачи

[Оглавление](README.md) · далее: [2 — стоимость и границы](02-theory-boundaries.md)

Цель — выбрать момент продажи по уже наблюдённой истории так, чтобы
максимизировать ожидаемую логарифмическую награду. Сначала зададим модель,
затем доступную информацию и множество допустимых решений.

## 1.1. Модель цены и нормировка

Пусть цена имеет вид

$$
S_t=S_0\exp\{at+\sigma B_t^H\},\qquad 0\le t\le T,
$$

где $a$ — снос логарифма цены, $\sigma>0$ — масштаб шума,
$T>0$ — горизонт, а $B^H$ — дробное броуновское движение с $0<H<1$.
При логарифмической полезности награда продажи относительно начальной цены —

$$
\log(S_\tau/S_0)=a\tau+\sigma B_\tau^H
=\sigma(\mu\tau+B_\tau^H),\qquad \mu=\frac a\sigma.
$$

Положительный множитель $\sigma$ не меняет оптимальный момент. Поэтому
для известных параметров задача зависит от $a,\sigma$ только через $\mu$.

```text
mu = a / sigma
X(t) = mu*t + B_H(t)
Нормированная награда продажи: X(tau).
```

Значение нормированной награды не является процентной доходностью цены.
Единица времени выбирается заранее; T не обязан равняться единице.

## 1.2. Дробное броуновское движение

Процесс $B^H$ центрирован и гауссовский. Его ковариация равна

$$
E[B_t^HB_s^H]=\frac12(t^{2H}+s^{2H}-|t-s|^{2H}).
$$

Отсюда $\mathrm{Var}(B_t^H-B_s^H)=|t-s|^{2H}$.
Приращения стационарны; их зависимость определяется H:

| Параметр | Непересекающиеся приращения |
|---|---|
| $H=1/2$ | независимы |
| $H>1/2$ | положительно коррелированы |
| $H<1/2$ | отрицательно коррелированы |

H характеризует зависимость и масштабирование шума, а не знак сноса.
При $H\ne1/2$ текущее значение само по себе в общем случае не содержит
всей информации для прогноза будущего.

Самоподобие означает равенство законов процессов

$$
(B_{ct}^H)_t\overset{d}=(c^HB_t^H)_t,\qquad c>0.
$$

Это свойство позволит пересчитывать стоимость и границы при изменении
горизонта. Определение и свойства fBm изложены в
[Simulation of fractional Brownian motion, §1.2](https://www.columbia.edu/~ad3217/fbm/thesis.pdf).

## 1.3. Даты решений и доступная история

Зададим сетку решений $0=t_0<t_1<\cdots<t_N=T$. Для равномерной сетки
$t_k=kT/N$: N — число интервалов, N+1 — число дат вместе с нулём.
Момент остановки должен принимать значения на этой сетке.

Фильтрация $\mathcal F_t$ описывает информацию, известную к моменту t.
В теоретической модели полной истории

$$
\mathcal F_t=\sigma(B_s^H:0\le s\le t).
$$

В модели конечных наблюдений используется меньшая информация, порождённая
наблюдёнными значениями процесса. Сетка наблюдений может быть подробнее
сетки решений. Увеличение числа наблюдений и добавление дат решений —
разные изменения задачи. При сравнении стоимостей фиксируется также фильтрация.

В нуле предполагается тривиальная $\mathcal F_0$: случайный шум ещё не наблюдался.
Поэтому допустимая стратегия либо останавливается в нуле почти наверное,
либо продолжается до первой положительной даты почти наверное.
Особенности этого предположения для вырожденного случая H=1 рассмотрены
в [главе 2](02-theory-boundaries.md).

## 1.4. Допустимый момент остановки и функция значения

Случайная дата $\tau$ допустима, если решение остановиться к дате $t_k$
принимается по информации этой даты:

$$
\{\tau\le t_k\}\in\mathcal F_{t_k},\qquad k=0,\ldots,N.
$$

Нельзя сначала увидеть всю будущую траекторию, а затем выбрать лучший день.
Для множества допустимых моментов $\mathcal T$ функция значения определяется как

$$
\boxed{V_T(\mu,H)=\sup_{\tau\in\mathcal T}E[\mu\tau+B_\tau^H].}
$$

```text
Награда одной траектории: R = mu*tau + B_H(tau).
V_T(mu,H) = наилучшая ожидаемая награда среди допустимых стратегий.
```

Если требуется подчеркнуть число дат, пишем $V_T^{(N)}$.
Для фиксированной допустимой стратегии $\pi$ её стоимость обозначается
$v_\pi(\mu,H)=E[X_{\tau_\pi}]$. Всегда $v_\pi\le V_T$, но равенство
без доказательства оптимальности не предполагается.

Уточнение вложенной сетки решений при сохранении доступной информации
не уменьшает V_T: прежние стратегии остаются допустимыми. В непрерывной
задаче разрешены все моменты остановки в $[0,T]$; это отдельное множество
допустимых решений. Конечность границ в следующих разделах сначала
рассматривается для фиксированной конечной сетки.
