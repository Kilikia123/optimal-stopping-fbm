# Теория оптимальной остановки дробного броуновского движения

Исследуется выбор момента продажи по наблюдённой истории процесса со сносом.
Текст последовательно объясняет постановку, границы, метод решения,
статистическую оценку и применение при неизвестных параметрах.

## Единые обозначения

| Обозначение | Значение |
|---|---|
| $T$, $N$, $t_k$ | Горизонт, число интервалов сетки решений, даты решений |
| $\mathcal F_t$ | Доступная к моменту t информация |
| $B_t^H$, $H$ | Дробное броуновское движение и показатель Херста |
| $a$, $\sigma$, $\mu=a/\sigma$ | Снос логарифма цены, масштаб шума, нормированный снос |
| $X_t=\mu t+B_t^H$ | Нормированная награда при остановке в t |
| $\pi$, $\tau_\pi$ | Фиксированная стратегия и выбранный ею момент остановки |
| $V_T$, $v_\pi$, $\widehat v_\pi$ | Истинный оптимум, стоимость стратегии, её выборочная оценка |
| $\mu_1$, $\mu_2$ | Точные левая и правая границы |
| $\mu_1^\varepsilon$, $\mu_2^\varepsilon$ | Практические границы допустимой потери стоимости |
| $\alpha$, $\varepsilon(H)=\alpha V_T(0,H)$ | Доля допуска и соответствующий абсолютный допуск |
| $R_i$, $Q_i$, $D_i=R_i-Q_i$ | Награда стратегии, награда удержания, парная разность |
| $M$, $SE$ | Размер независимого теста и стандартная ошибка среднего |
| $\beta$, $1-\beta$ | Вероятность непокрытия и уровень доверия |
| $K$ | Порядок усечения сигнатуры |
| $Y_k$, $C_k$ | Условная оптимальная стоимость и стоимость продолжения |

Подстрочный T у V подчёркивает горизонт. Верхний индекс N используется,
когда нужно подчеркнуть зависимость от сетки. Шляпка означает оценку по данным.
Условные стоимости Y_k и C_k — случайные величины, зависящие от истории;
V_T и v_pi — их ожидаемые, а не потраекторные значения.

## Основные источники

- Bayer, Pelizzari, Schoenmakers,
  [Primal and dual optimal stopping with signatures](https://arxiv.org/abs/2312.03444)
  — приближение стратегии и мартингальные верхние оценки.
- Bayer, Hager, Riedel, Schoenmakers,
  [Optimal stopping with signatures](https://www.wias-berlin.de/people/bayerc/files/hager_riedel_schoenmakers_21.pdf)
  — сигнатурные методы и дискретная предельная модель H→0.
- Dieker,
  [Simulation of fractional Brownian motion](https://www.columbia.edu/~ad3217/fbm/thesis.pdf)
  — свойства и моделирование fBm.
