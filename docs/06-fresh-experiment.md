# Новый эксперимент: 100 000 train и 100 000 test

Это полный новый расчёт сетки H × μ. Старые стратегии и старые границы не используются.

1. В `03-grid.ipynb` задайте новый `RUN_ID`, `M_train=100_000`, `M_test=100_000`.
   По умолчанию H=0,06,…,0,96 с шагом 0,02, μ=−4,…,9 с шагом 0,01.
2. Выполните ячейки сверху вниз. Для каждого узла обучение идёт заново.
   Регрессии используют все 100 000 обучающих траекторий. Дополнительные
   10 000 независимых валидационных траекторий выбирают единственное действие
   в нуле: остановиться или продолжить. Это решение фиксируется до теста.
3. На 100 000 независимых тестовых траекторий посчитайте награды стратегии.
   Среднее, SE и интервалы сохраняются сразу после каждого узла. Тест считается
   блоками по 2 000; после прерывания тот же RUN_ID продолжает расчёт.
4. В `04-grid-analysis.ipynb` укажите тот же RUN_ID и выполните ячейки.
   H выбирает локальный график, EPSILON — порог практических границ. Общий график
   показывает обе границы по всем H. Анализ не вызывает обучения/симуляции.

## Доверительный интервал V

Для новой обученной стратегии тестовые награды равны
$Y_i=\mu\tau_i+B^H_{\tau_i}$. Оцениваем:

$$
\bar Y=\frac{1}{M}\sum_iY_i,\quad
s^2=\frac{\sum_i(Y_i-\bar Y)^2}{M-1},\quad SE=s/\sqrt{M}.
$$

95%-й точечный интервал — $\bar Y\pm t_{M-1;0.975}SE$, примерно ±1,96 SE.
Стратегия не меняется по результатам теста; новое среднее не обрезается снизу.
Если выбрана остановка в нуле, награды точно нулевые и интервал [0,0].

Интервал характеризует тестовую погрешность **новой** стратегии, условно на
её обучении и валидации. Он не оценивает разброс стратегий между разными
обучающими seed и не доказывает близость к истинному оптимуму.

## Интервалы μ

Используется вся заранее заданная сетка, без выбора окон из старого эксперимента.
Для K=len(H_grid)×len(mu_grid) строится общая полоса
$\bar Y_j\pm t_{M-1;1-0.05/(2K)}SE_j$.
Зависимость оценок между μ из-за общих траекторий допустима для Бонферрони.
Полоса консервативна; при полной сетке она шире точечных интервалов.

Для первой границы сравниваем стоимость с ε, для второй — стоимость минус μT.
Пусть A — узлы, у которых верх полосы ≤ε, B — узлы, у которых низ полосы ≤ε.
На событии покрытия полоса даёт:

$$
\mu_1\in[\max A,\max B],\qquad \mu_2\in[\min B,\min A].
$$

Требуем достоверно находиться по разные стороны порога на концах сетки.
Иначе показываем «нужно расширить сетку». При повторных переходах показываем
неоднозначность. Интервалы не строятся по неполному H. Совпадение концов
означает определённый сеточный узел, а не точную непрерывную границу.
Покрытие приближённое: награды остановленной стратегии не обязаны быть нормальными.

## Файлы и память

- `experiment.json` — полный конфиг, seed train/validation/test, версии и семейство узлов.
- `policies/` — новые стратегии; `states/` — прогресс теста; `nodes/` — готовые оценки с интервалами.
- `analysis/epsilon_<значение>/` — общие CSV и рисунки после запуска анализа.

Сигнатуры строятся блоками; для обучения сохраняются только значения на датах
решения. При стандартной конфигурации массив обучающих признаков занимает
около 496 МБ, вместо примерно 5 ГБ для сигнатур на всех мелких датах.
Это размер одного массива, не предел общего расхода памяти. Полная сетка —
59 846 отдельных обучений, поэтому полный запуск может быть длительным.

Старые режимы `grid` / `legacy` остаются доступны. Код прежней проверки старых
стратегий сохранён в библиотеке, но текущие ноутбуки по умолчанию запускают
именно новый эксперимент, без `AUDIT_SETTINGS` и без исходного SOURCE_RUN_ID.
