# 2. Стоимость и границы оптимальной остановки

[← 1 — постановка](01-problem-setup.md) · [оглавление](README.md) · далее: [3 — метод решения](03-method-signatures.md)

Две простые стратегии дают точки сравнения: остановиться сразу или держать
до конца. Сначала определим, когда они точно оптимальны, затем разрешим
небольшую потерю стоимости. Это разные виды границ.

## 2.1. Функция значения и опорные стратегии

При фиксированной сетке $`0=t_0<\dots<t_N=T`$ исследуется

```math
V_T(\mu,H)=\sup_{\tau\in\mathcal T}E[\mu\tau+B^H_\tau].
```

Стратегии $`\tau=0`$ и $`\tau=T`$ дают соответственно $`0`$ и $`\mu T`$, поэтому

```math
V_T(\mu,H)\ge\max(0,\mu T).
```

Решения разрешены только на сетке, но теоретическая фильтрация содержит всю
историю процесса до даты решения. Численная аппроксимация использует историю на
мелкой сетке. Ниже предполагается $`N\ge2`$, кроме явно выделенного случая $`N=1`$.

```text
Остановиться сразу: ожидаемая награда 0.
Держать до конца: ожидаемая награда mu*T.
V_T(mu,H) >= max(0, mu*T).
```

## 2.2. Свойства стоимости по сносу

$`V_T`$ — супремум аффинных функций $`\mu E[\tau]+E[B^H_\tau]`$ с наклонами
в $`[0,T]`$. Поэтому она конечна, непрерывна, выпукла, не убывает и является
$`T`$-липшицевой. Функция $`W_T=V_T-\mu T`$ выпукла, не возрастает и неотрицательна.
Множество нулевых значений замкнуто; его границу определим далее.

В точках дифференцируемости истинного значения для оптимальной стратегии

```math
\partial_\mu V_T(\mu,H)=E[\tau^*(\mu,H)].
```

Это свойство истинного оптимума; стоимость произвольной фиксированной
стратегии не обязана иметь ту же производную.
Как следует из строгой положительности выигрыша над удержанием, доказанной
в разделе 2.3, при $`H\ne1/2`$ производная, где она существует, не достигает $`T`$ при
конечном $`\mu`$: иначе выпуклая невозрастающая $`W_T`$ стала бы постоянной справа,
что противоречит её строгой положительности и пределу ноль.

## 2.3. Точные границы

```math
\mu_1(H,T)=\sup\{\mu:V_T(\mu,H)=0\},\qquad
\mu_2(H,T)=\inf\{\mu:V_T(\mu,H)=\mu T\}.
```

Для пустых множеств принимаются $`\inf\varnothing=+\infty`$ и
$`\sup\varnothing=-\infty`$.

**Левая граница конечна.** Фильтрация в нуле тривиальна. Если стратегия не
останавливается в нуле, то $`\tau\ge t_1`$ почти наверное. При $`\mu<0`$

```math
E[\mu\tau+B^H_\tau]\le\mu t_1+E[\max_{1\le k\le N}B^H_{t_k}].
```

При достаточно отрицательном $`\mu`$ правая часть отрицательна, поэтому
немедленная остановка оптимальна. При $`\mu>0`$ имеем $`V_T\ge\mu T>0`$.

**Правая граница при $`H\ne1/2`$ бесконечна.** Выберем любую промежуточную дату
$`t\in(0,T)`$ и обозначим

```math
c=\mathrm{Cov}(B^H_t,B^H_T-B^H_t)
=\tfrac12(T^{2H}-t^{2H}-(T-t)^{2H}),\qquad
Y=E[B^H_T-B^H_t\mid B^H_t]=\frac{c}{t^{2H}}B^H_t.
```

При $`H\ne1/2`$ имеем $`c\ne0`$ (строгая выпуклость или вогнутость степени),
поэтому $`Y`$ — невырожденная центрированная гауссовская величина. Стратегия
«остановиться в $`t`$, если $`\mu(T-t)+Y<0`$, иначе в $`T`$» допустима и даёт

```math
E[X_\tau]-\mu T=E[(-\mu(T-t)-Y)_+]>0
```

для каждого конечного $`\mu`$. Следовательно,

```math
\boxed{V_T(\mu,H)>\mu T,\qquad\mu_2(H,T)=+\infty\quad(H\ne1/2).}
```

При $`\mu=0`$ то же доказательство даёт $`V_T(0,H)>0`$, поэтому $`\mu_1(H,T)<0`$.
Для вывода используются только свойства гауссовского процесса.

При $`\mu\to+\infty`$ превышение стоимости над удержанием стремится к нулю:

```math
0\le V_T-\mu T\le E\![\max_{0\le k\le N}
\{B^H_{t_k}-B^H_T-\mu(T-t_k)\}]\longrightarrow0.
```

Максимум неотрицателен благодаря $`k=N`$, сходится к нулю потраекторно и при
$`\mu\ge0`$ ограничен интегрируемым максимумом абсолютных приращений.

Точные режимы при $`H\ne1/2`$: слева допустима оптимальная стратегия $`\tau=0`$;
при $`\mu>\mu_1`$ оптимальная стратегия использует информацию истории. Конечного
правого режима «всегда держать» нет. На самой левой границе оптимум может быть
неединственным. Точная разность $`\mu_2-\mu_1`$ бесконечна и не служит конечной
мерой ценности тайминга.

```text
Точная левая = sup{mu : V_T(mu,H) = 0}.
Точная правая = inf{mu : V_T(mu,H) = mu*T}.
```

В этих определениях нет допуска потери. Конечная левая граница означает,
что при достаточно отрицательном сносе продолжать невыгодно даже в среднем.
Бесконечная правая означает, что любой конечный снос оставляет ненулевую
возможность улучшить удержание на редких траекториях.

## 2.4. Практические границы с абсолютным допуском

Выбираем $`\varepsilon>0`$ **в единицах награды**, независимо от стандартной
ошибки Monte Carlo, и на всей оси $`\mu\in\mathbb R`$ определяем

```math
\boxed{\mu_1^\varepsilon(H,T)=\sup\{\mu:V_T(\mu,H)\le\varepsilon\},\qquad
\mu_2^\varepsilon(H,T)=\inf\{\mu:V_T(\mu,H)-\mu T\le\varepsilon\}.}
```

Обе границы конечны. Области близости к опорным стоимостям — лучи
$`(-\infty,\mu_1^\varepsilon]`$ и $`[\mu_2^\varepsilon,+\infty)`$.

| Условие | Значение |
|---|---|
| $`\mu\le\mu_1^\varepsilon`$ | Выигрыш истинного оптимума относительно немедленного выхода не более $`\varepsilon`$ |
| $`\mu\ge\mu_2^\varepsilon`$ | Выигрыш истинного оптимума относительно удержания не более $`\varepsilon`$ |
| $`\mu_1^\varepsilon<\mu<\mu_2^\varepsilon`$ (если интервал непуст) | Обе опорные стратегии уступают оптимуму более чем на $`\varepsilon`$ |

Близость **стоимости** не означает, что все траектории останавливаются в нуле
или в конце. Вводим **разность практических границ**

```math
D_\varepsilon(H,T)=\mu_2^\varepsilon(H,T)-\mu_1^\varepsilon(H,T).
```

Она может быть отрицательной: тогда области близости перекрываются, а длина
перекрытия равна $`-D_\varepsilon`$. Это не ошибка и не «отрицательная ширина
области тайминга». При увеличении $`\varepsilon`$ левая граница не убывает,
правая не возрастает. Для $`\varepsilon\downarrow0`$ при $`H\ne1/2`$
$`\mu_1^\varepsilon\to\mu_1`$, а $`\mu_2^\varepsilon\to+\infty`$.

```text
Левая практическая = sup{mu : V_T(mu,H) <= epsilon}.
Правая практическая = inf{mu : V_T(mu,H) - mu*T <= epsilon}.
```

Практическая левая граница не меньше точной левой. Между ними продолжение
уже выгоднее немедленной остановки, но выигрыш ещё не превышает epsilon.
Практическая правая граница может быть конечной, даже если точная бесконечна.

## 2.5. Относительный допуск: роль alpha

Относительный допуск сохраняет сравнения с остановкой сразу и удержанием, но выбирает
$`\varepsilon(H)=\alpha V_T(0,H)`$, где одна доля $`0<\alpha<1`$ используется
для всех $`H`$. При нулевом дрейфе обе опорные стратегии имеют нулевую
ожидаемую награду, поэтому $`V_T(0,H)`$ — ценность тайминга в этой точке.

Те же определения в записи для терминала:

```text
epsilon(H) = alpha * V_T(0, H),    0 < alpha < 1

mu_left  = sup{mu : V_T(mu, H) <= epsilon(H)}
mu_right = inf{mu : V_T(mu, H) - mu*T <= epsilon(H)}
```

`sup` — верхняя граница множества, `inf` — нижняя.
При каждом фиксированном H допуск epsilon(H) один и тот же для всех mu.

При $`H\ne1/2`$, $`N\ge2`$ имеем $`V_T(0,H)>\varepsilon(H)>0`$.
Непрерывность и монотонность по $`\mu`$ дают
$`\mu_1^{\varepsilon(H)}<0<\mu_2^{\varepsilon(H)}`$: относительные границы
не пересекаются. При $`H=1/2`$ используем аналитические значения
$`\varepsilon=\mu_1=\mu_2=0`$, а не инверсию шумной оценки. Утверждение о
строгих знаках не распространяется на $`N=1`$, где ценность тайминга равна нулю.

```text
alpha меньше -> epsilon меньше -> левая граница левее, правая правее.
alpha больше -> epsilon больше -> левая граница правее, правая левее.
```

Alpha — доля стоимости тайминга при нулевом сносе. Она не является
вероятностью ошибки или долей траекторий, на которых разрешено ошибиться.
Знак границ и монотонность по alpha не доказывают монотонность по H.
Симметрия относительно H=1/2 и сходимость относительных границ к нулю
при приближении к H=1/2 требуют отдельных обоснований.

## 2.6. Масштабирование по горизонту

Самоподобие fBm и замена $`\tau=Ts`$ при одинаковом числе дат и согласованной
масштабируемой информации дают

```math
V_T(\mu,H)=T^H V_1(\mu T^{1-H},H).
```

Точные границы масштабируются как $`\mu_i(H,T)=T^{H-1}\mu_i(H,1)`$,
с пониманием $`\mu_2=+\infty`$ при $`H\ne1/2`$, $`N\ge2`$.
Для **фиксированного абсолютного допуска** необходимо масштабировать и его:

```math
\boxed{\mu_i^\varepsilon(H,T)=T^{H-1}
\mu_i^{\varepsilon/T^H}(H,1),\qquad i=1,2.}
```

Та же формула верна для $`D_\varepsilon`$. Если допуск на горизонте $`T`$ выбран
равным $`T^H\varepsilon_1`$, тогда границы равны $`T^{H-1}`$ от границ при $`T=1`$
с допуском $`\varepsilon_1`$. Допуск масштабируется вместе с единицами награды.

## 2.7. Аналитические случаи

В этом разделе проверяются общие определения на моделях, допускающих
явное решение. Непрерывное время и конечные сетки рассматриваются раздельно.
Для H=1 горизонт нормирован к T=1; перенос на другие горизонты
следует из предыдущего раздела при соответствующих предположениях.

### 2.7.1. Броуновский случай H = 1/2

Для $`X_t=\mu t+B_t`$ и любого
допустимого ограниченного момента остановки по теореме об остановке

```math
E[B_\tau]=0,\qquad E[X_\tau]=\mu E[\tau].
```

Так как $`0\le E[\tau]\le T`$, получаем

```math
V_T(\mu,1/2)=\max(0,\mu T),\qquad\mu_1(1/2,T)=\mu_2(1/2,T)=0.
```

При $`\mu<0`$ оптимально остановиться сразу, при $`\mu>0`$ — в конце. При
$`\mu=0`$ любая допустимая стратегия оптимальна, но преимущества от тайминга нет.
Вывод одинаков для непрерывного времени и любой сетки, содержащей $`0,T`$:
дискретизация не меняет ни стоимость, ни точные границы. Левую точную границу определяет супремум множества сносов,
при которых остановка в нуле оптимальна.

Для практических границ на всей оси

```math
\boxed{\mu_1^\varepsilon(1/2,T)=\varepsilon/T,\quad
\mu_2^\varepsilon(1/2,T)=-\varepsilon/T,\quad
D_\varepsilon(1/2,T)=-2\varepsilon/T.}
```

При $`N=1`$ (только $`0,T`$) эти формулы справедливы для любого $`H`$: промежуточного
решения нет. Доказательство бесконечности правой границы требует $`N\ge2`$.

### 2.7.2. Вырожденный случай H = 1

При $`H=1`$ ковариация равна $`st`$, и вырожденный гауссовский процесс имеет вид

```math
B_t^1=\xi t,\qquad \xi\sim N(0,1),\qquad X_t=(\mu+\xi)t.
```

Этот случай рассматривается как отдельный аналитический эталон на границе
диапазона параметра Херста. В этом разделе $`T=1`$, а $`\varphi`$ и $`\Phi`$ —
плотность и функция распределения стандартной нормальной величины.
Для произвольной стратегии верно

```math
E[X_\tau]=E[(\mu+\xi)\tau].
```

В общем случае $`\tau`$ зависит от $`\xi`$, поэтому произведение нельзя
разделять на ожидания. При любом $`t>0`$ наблюдение $`X_t`$ определяет наклон
$`\mu+\xi=X_t/t`$ без ошибки.

#### Непрерывное время: значение и достижимость

При известном наклоне наилучший выбор потраекторно — остановиться в нуле
при $`\xi<-\mu`$ и в единице при $`\xi>-\mu`$. Его ожидаемая награда равна

```math
f(\mu)=E[(\mu+\xi)_+]
=\int_{-\mu}^{\infty}(\mu+x)\varphi(x)\,dx
=\mu\Phi(\mu)+\varphi(\mu).
```

**При принятой в работе тривиальной $`\mathcal F_0`$ этот выбор не является
допустимым моментом остановки:** событие остановки в нуле зависит от ещё
неизвестной $`\xi`$. Но для любого $`0<\delta<1`$ допустима стратегия

```math
\tau_\delta=
\begin{cases}
\delta,&\mu+\xi<0,\\
1,&\mu+\xi\ge0.
\end{cases}
```

К моменту $`\delta`$ наклон уже известен, и

```math
E[X_{\tau_\delta}]
=f(\mu)+\delta\,E[(\mu+\xi)\mathbf1_{\{\mu+\xi<0\}}]
=f(\mu)+\delta[\mu\Phi(-\mu)-\varphi(\mu)]
\longrightarrow f(\mu).
```

С другой стороны, $`X_\tau\le(\mu+\xi)_+`$ для любого $`0\le\tau\le1`$.
Значит, непрерывная задача имеет супремум

```math
\boxed{V^{\mathrm{cont}}_1(\mu,1)=f(\mu).}
```

Для каждого конечного $`\mu`$ этот супремум при тривиальной $`\mathcal F_0`$
не достигается: равенство потраекторной верхней оценке требует остановки
в нуле ровно на событии отрицательного наклона. Если же $`\xi`$ включена
в информацию нулевого момента, стратегия выбора между нулём и единицей допустима
и достигает $`f(\mu)`$. В частности, правостороннее расширение естественной
фильтрации при $`H=1`$ раскрывает $`\xi`$ уже в нуле и меняет это предположение.

Поскольку $`f(\mu)>0`$ и $`f(\mu)-\mu=f(-\mu)>0`$ при любом конечном сносе,
точные границы непрерывной задачи равны

```math
\boxed{\mu_1^{\mathrm{cont}}(1,1)=-\infty,\qquad
\mu_2^{\mathrm{cont}}(1,1)=+\infty.}
```

Здесь используется $`\sup\varnothing=-\infty`$ для левого множества.

#### Равномерная сетка: стоимость продолжения и полная стоимость

Пусть решения разрешены в $`0,1/N,\ldots,1`$, $`N\ge2`$, и информация в нуле
тривиальна. Если в нуле принято продолжать, оптимальная стратегия имеет вид

```math
\tau_N^{\mathrm{continue}}=
\begin{cases}
1/N,&\mu+\xi<0,\\
1,&\mu+\xi\ge0.
\end{cases}
```

После первого положительного наблюдения вся траектория известна. Поэтому
при отрицательном наклоне следует выйти в первую доступную дату, при
положительном — в последнюю. Стоимость этого продолжения равна

```math
\begin{aligned}
C_N(\mu)
&=f(\mu)+\frac1N[\mu\Phi(-\mu)-\varphi(\mu)]\\
&=\frac\mu N+(1-\frac1N)f(\mu).
\end{aligned}
```

Стоимость продолжения $`C_N`$ может быть отрицательной. Поскольку в полной
задаче можно выбрать
$`\tau\equiv0`$, её функция значения —

```math
\boxed{V_1^{(N)}(\mu,1)=\max\{0,C_N(\mu)\}.}
```

```text
f(mu) = mu*Phi(mu) + phi(mu)
C_N(mu) = mu/N + (1 - 1/N)*f(mu)
V_1^(N)(mu, H=1) = max(0, C_N(mu))

Phi — функция распределения стандартной нормальной величины.
phi — её плотность.
```

Если $`C_N<0`$, оптимальна остановка в нуле; если $`C_N>0`$, оптимальна
описанная стратегия продолжения; при равенстве допустимы оба выбора.
Для $`N=1`$ формула даёт $`C_1=\mu`$ и $`V_1^{(1)}=\max(0,\mu)`$,
то есть информационного преимущества нет.

#### Точные границы и влияние числа дат

Для $`N\ge2`$ имеем

```math
C_N'(\mu)=\frac1N+(1-\frac1N)\Phi(\mu)>0.
```

Кроме того, $`C_N(\mu)\to-\infty`$ при $`\mu\to-\infty`$, а $`C_N(0)>0`$.
Следовательно, существует единственный отрицательный корень $`a_N`$:

```math
C_N(a_N)=0,\qquad
\boxed{\mu_1^{(N)}(1,1)=a_N> -\infty.}
```

Для правой границы

```math
C_N(\mu)-\mu=(1-\frac1N)f(-\mu)>0,
\qquad \boxed{\mu_2^{(N)}(1,1)=+\infty.}
```

При росте $`N`$ стоимость $`C_N`$ возрастает к $`f`$, а $`a_N`$ убывает
к $`-\infty`$: для любого фиксированного конечного $`\mu`$ предел
$`C_N(\mu)=f(\mu)>0`$. Таким образом, в отличие от $`H=1/2`$,
дискретизация существенно влияет на левую точную границу при $`H=1`$.

#### Практические границы при относительном допуске

Для $`N\ge2`$ и $`\varepsilon>0`$ практические границы определяются уравнениями

```math
C_N(\mu_1^\varepsilon)=\varepsilon,\qquad
\max\{0,C_N(\mu_2^\varepsilon)\}-\mu_2^\varepsilon=\varepsilon.
```

В относительном режиме

```math
V_1^{(N)}(0,1)=(1-\frac1N)\varphi(0),\qquad
\varepsilon_N=\alpha(1-\frac1N)\varphi(0),\qquad 0<\alpha<1.
```

Тогда $`\mu_1^{\varepsilon_N}<0<\mu_2^{\varepsilon_N}`$, и для правой границы
уравнение упрощается до

```math
f(-\mu_2^{\varepsilon_N})=\alpha\varphi(0).
```

Поэтому правая относительная граница при $`H=1`$ не зависит от $`N\ge2`$
при фиксированной доле $`\alpha`$; левая зависит от сетки.

Конечная правая ε-граница совместима с бесконечной точной границей: за ней
удержание уступает оптимуму не более чем на ε, хотя выигрыш тайминга всё ещё
