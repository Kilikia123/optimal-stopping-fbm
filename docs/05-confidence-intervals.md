# Доверительные интервалы стоимости стратегии и практических границ

## Запуск

1. Откройте `notebooks/03-grid.ipynb`, оставьте `MODE="audit"`.
2. Укажите исходный `SOURCE_RUN_ID` и новый `AUDIT_ID`. По умолчанию проверяется
   запуск `20260915T145421_404840Z`, все его H, ε=0,03, 100 000 новых траекторий
   на H, блоки по 2 000. Окна расширяют исходные брекеты на 0,10 в обе стороны.
3. Выполните ячейки сверху вниз. Для продолжения используйте тот же ID и параметры.
   Настройки, состав узлов, seed, версии библиотек и хэш реализации фиксируются
   в `audits/<AUDIT_ID>/manifest.json`. Изменение требует нового ID.
4. Откройте `notebooks/04-grid-analysis.ipynb`, оставьте `ANALYSIS_MODE="audit"`,
   укажите тот же исходный запуск и ID проверки. H выбирает локальный график;
   общий график включает все H. EPSILON в этом ноутбуке относится только к
   старому анализу: проверка использует допуск из manifest.
5. Таблицы `values.csv`, `boundaries.csv` и рисунки сохраняются в
   `audits/<AUDIT_ID>/analysis/`. Анализ можно повторять без обучения.

`MODE="grid"` и `ANALYSIS_MODE="legacy"` сохраняют прежний рабочий процесс.
Старые таблицы узлов не перезаписываются. Полный тест запускает пользователь:
он существенно дороже небольшого проверочного примера.

## Что является объектом оценки

Для каждой пары (H, μ) исходный алгоритм обучил отдельную стратегию π.
Проверяем **её ожидаемую награду**

\[
v_\pi(\mu,H)=E[\mu\tau_\pi+B^H_{\tau_\pi}].
\]

Это не обязательно оптимальная стоимость V*. Для исследования границ получаем
семейство разных стратегий π(H,μ); его стоимость не обязана быть монотонной.

Старые файлы содержат средние, но не коэффициенты регрессии. Поэтому сначала
воспроизводим обучение с прежними seed и проверяем совпадение со старым V_raw
(`rtol=1e-7`, `atol=1e-9`). Коэффициенты и действие в нуле сохраняются в JSON.

Старое действие в нуле было выбрано по старому тесту. Для **нового независимого
теста** оно уже фиксировано. Условно на старых данных это допустимая стратегия,
а новое среднее не участвует в выборе действия. Если было выбрано остановиться
в нуле, все новые награды равны нулю и интервал точно равен [0,0]. Это не
доказывает, что оптимальная стоимость равна нулю.

## Среднее, стандартное отклонение и SE

После фиксации стратегии генерируем независимые траектории и получаем награды

\[
Y_i=\mu\tau_i+B^H_{\tau_i},\quad i=1,\dots,M.
\]

В каждом узле награды независимы между траекториями. Между разными μ оценки
зависимы: для снижения шума сравнений используются общие траектории.

\[
\bar Y=\frac1M\sum_iY_i,\qquad
s^2=\frac1{M-1}\sum_i(Y_i-\bar Y)^2,\qquad SE=\frac{s}{\sqrt M}.
\]

`s` — разброс отдельных наград; `SE` — оценка ошибки их среднего. Например,
при s=0,8 и M=100 000 получаем SE≈0,00253 и обычную полуширину интервала ≈0,00496.
Увеличение M в четыре раза уменьшает SE примерно вдвое при той же стратегии.

Суммы не требуют хранения всех наград. Для объединения старых n наблюдений
со средним a и суммой квадратов S с блоком размера m, средним b и суммой Q:

\[
\delta=b-a,\quad a'=a+\delta\frac{m}{n+m},\quad
S'=S+Q+\delta^2\frac{nm}{n+m}.
\]

Эти три числа и номер следующего блока атомарно сохраняются для каждого узла.
Seed блока фиксирован заранее; после сбоя недостающий блок воспроизводится.

## Точечный интервал стоимости

При доверии 1−α:

\[
I_V=[\bar Y-qSE,\bar Y+qSE],\qquad q=t_{M-1;1-\alpha/2}.
\]

Для 95% и большого M значение q близко к 1,96. Интервал не является точным
конечновыборочным интервалом: награды остановленной стратегии не обязаны иметь
нормальное распределение. Используется приближение для среднего при большом M.
Редкие события и асимметрия могут ухудшить покрытие; маленький SE не контролирует
ошибку обучения.

95% — характеристика процедуры при повторных независимых тестах фиксированной
стратегии, а не вероятность нахождения уже фиксированного параметра в конкретном
полученном интервале и не доля попадающих туда отдельных наград.

Новый тест имеет заранее заданный размер. Просмотр промежуточных результатов
не должен превращаться в правило «остановиться, когда интервал стал подходящим».
Промежуточные узлы отмечаются incomplete и не используются для финальной локализации.

## Общая полоса для границ

Граница выбирается после сравнения многих узлов с порогом. Отдельные 95%-е
интервалы не обеспечивают 95%-го покрытия всей кривой. Поэтому до теста фиксируем
K — число различных пар (H, μ) во всех выбранных окнах всех H — и применяем
поправку Бонферрони:

\[
[L_j,U_j]=[\bar Y_j-q_KSE_j,\bar Y_j+q_KSE_j],\qquad
q_K=t_{M-1;1-\alpha/(2K)}.
\]

Объединение событий непокрытия даёт суммарную вероятность не более α, если
каждый отдельный интервал имеет заявленное покрытие. Здесь это **приближённое**
утверждение, поскольку исходные t-интервалы приближённые. Независимость между
узлами для Бонферрони не нужна. Поправка консервативна, особенно при корреляции.
K не уменьшается при просмотре одного H или незавершённого расчёта.

Для правой границы исследуется превышение над удержанием:

\[
g_j=v_{\pi_j}(\mu_j,H)-\mu_jT.
\]

μT известно точно, поэтому интервал равен [L_j−μ_jT,U_j−μ_jT]; SE не меняется.
Дополнительная поправка за эти сдвинутые интервалы не нужна: они покрываются
тем же событием покрытия исходных стоимостей.

## От полосы стоимости к интервалу μ

Внутри выбранного окна определяем сеточную левую границу как последний μ,
для которого стоимость стратегии ≤ε, правую — как первый μ, для которого
превышение над удержанием ≤ε. Это локальные сеточные аналоги, не непрерывные
границы на всей вещественной оси.

Для соответствующей полосы в каждом случае вводим:

- A = {μ: U(μ)≤ε}: узлы, определённо входящие в пороговую область;
- B = {μ: L(μ)≤ε}: узлы, которые могут входить в неё.

На событии общего покрытия истинное пороговое множество C удовлетворяет
A⊆C⊆B. Следовательно:

\[
\max A\le\mu_1\le\max B,\qquad
\min B\le\mu_2\le\min A.
\]

Для первой границы требуем, чтобы левый конец окна определённо входил, а
правый определённо не входил в область. Для второй — наоборот. Без этого
выдаём `expand_window`, а не конечный интервал. Повторные переходы средних
выдают `multiple_transitions`: монотонность не навязывается сглаживанием.

Пример: последние определённо/возможно входящие узлы первой области равны
−0,23 и −0,19. Тогда интервал сеточной μ₁ равен [−0,23;−0,19]. Это следует из
полосы стоимости, а не из переноса SE на ось μ.

Если концы совпали, определён узел исходной сетки. Это не нулевая погрешность
непрерывной границы: между узлами ничего не интерполируется. Шаг сетки сохраняется
отдельно (`grid_step_min`, `grid_step_max`). За пределами проверенного окна
отсутствие других переходов не доказано.

При расширении окна создайте новый эксперимент и используйте новый тестовый
seed: выбор расширения по уже просмотренному тесту не должен повторно использовать
те же наблюдения как независимую проверку. Интервалы нового эксперимента не
являются совместной гарантией для неограниченного числа последующих попыток.

## Статусы и ограничения

- `localized_grid`: есть интервал локализации сеточной границы в окне.
- `expand_window`: достоверного окружения перехода с двух сторон нет.
- `multiple_transitions`: средние имеют повторные переходы порога.
- `incomplete_test`: хотя бы один требуемый узел не завершён.
- `source_not_localized`: исходный скан не локализовал границу.
- `source_incomplete`: исходная сетка H рассчитана не полностью.

Не учитываются изменение стратегии при другом обучающем seed, ошибка сигнатурной
аппроксимации, временная дискретизация и разница между стоимостью стратегии и
истинным оптимумом. Для последнего нужна также верхняя оценка; в этой проверке
её нет. Монотонность по H по графику автоматически не объявляется доказанной.
