# 2. Исходная модель цены

Предполагается, что динамика цены актива описывается процессом

\[
S_t = S_0 \exp\{at+\sigma B_t^H\},
\]

где:

- \(S_t\) — цена актива в момент времени \(t\);
- \(S_0\) — цена в начале рассматриваемого периода;
- \(a\) — drift, то есть детерминированная составляющая роста;
- \(\sigma\) — масштаб случайных колебаний;
- \(B_t^H\) — fractional Brownian motion;
- \(H\) — параметр Херста.

Рабочий горизонт — один месяц:

\[
T=1.
\]

Месяц разбивается примерно на 20 торговых дней:

\[
t_k = \frac{k}{20}, \qquad k=0,\ldots,20.
\]

В каждый из этих моментов разрешено принять решение о продаже.

---

# 3. Fractional Brownian Motion

Fractional Brownian motion (fBm)

\[
B_t^H
\]

— центрированный гауссовский процесс:

\[
E[B_t^H]=0,
\]

с ковариационной функцией

\[
\operatorname{Cov}(B_t^H,B_s^H)
=
\frac12
\left(
t^{2H}+s^{2H}-|t-s|^{2H}
\right).
\]

Главный параметр:

\[
H\in(0,1).
\]

Интерпретация:

- \(H=1/2\) — обычное Brownian motion;
- \(H>1/2\) — положительная зависимость приращений, persistence;
- \(H<1/2\) — отрицательная зависимость приращений, anti-persistence.

Именно \(H\) позволяет учитывать автокорреляционную структуру движения цены.

Для теории fBm используется работа Tom Dieker, а в основной статье наиболее важен **Section 4.1 — Fractional Brownian Motion**.

# 4. Постановка задачи optimal stopping

Необходимо выбрать момент продажи

\[
\tau\in\mathcal T,
\]

где \(\tau\) является stopping time.

Это означает, что решение в момент \(t\) может использовать только информацию, известную к моменту \(t\). Нельзя увидеть всю будущую траекторию и после этого выбрать лучший день продажи.

Предлагается использовать логарифмическую функцию полезности:

\[
U(S)=\ln S.
\]

Тогда исходная задача:

\[
\sup_{\tau\in\mathcal T}E[\ln S_\tau].
\]

Подставляя модель цены,

\[
\ln S_\tau
=
\ln S_0+a\tau+\sigma B_\tau^H.
\]

Поскольку \(\ln S_0\) является константой, она не влияет на оптимальный момент остановки:

\[
\sup_\tau E[a\tau+\sigma B_\tau^H].
\]

Далее делим на положительную величину \(\sigma\):

\[
\sup_\tau
E\left[
\frac{a}{\sigma}\tau+B_\tau^H
\right].
\]

Вводим нормированный drift

\[
\mu=\frac{a}{\sigma}.
\]

Получаем центральную задачу работы:

\[
\boxed{
V(\mu,H)
=
\sup_{\tau\in\mathcal T}
E[\mu\tau+B_\tau^H].
}
\]

Для краткости в теоретической части можно снова обозначать нормированный drift буквой \(a\):

\[
\boxed{
V(a,H)
=
\sup_{\tau\in\mathcal T}
E[a\tau+B_\tau^H].
}
\]

Важно различать:

\[
Z_\tau=a\tau+B_\tau^H
\]

— reward одной конкретной траектории при выбранном stopping time,

а

\[
V(a,H)
\]

— максимальный ожидаемый reward среди всех допустимых stopping strategies.

# 6. Snell envelope, Dynamic Programming Principle и Bellman recursion

Для reward process \(Z_t\) Snell envelope определяется как

\[
Y_t
=
\operatorname{ess\,sup}_{\tau\ge t}
E[Z_\tau\mid\mathcal F_t].
\]

В дискретном времени выполняется рекурсия

\[
\boxed{
Y_t
=
\max
\left\{
Z_t,\;
E[Y_{t+1}\mid\mathcal F_t]
\right\}.
}
\]

Это Dynamic Programming Principle и одновременно форма Bellman recursion для задачи optimal stopping.

Есть два действия:

\[
STOP
\qquad\text{или}\qquad
CONTINUE.
\]

Если останавливаемся сейчас, получаем

\[
Z_t.
\]

Если продолжаем, рассматриваем continuation value

\[
\boxed{
C_t
=
E[Y_{t+1}\mid\mathcal F_t].
}
\]

Правило решения:

\[
Z_t\ge C_t
\Rightarrow STOP,
\]

\[
Z_t<C_t
\Rightarrow CONTINUE.
\]

Основная база по этому блоку находится в **Section 3.2** статьи.

# 7. Почему возникает необходимость в Signatures

Для марковского процесса continuation value можно было бы искать в виде

\[
C_t=f(X_t).
\]

Однако fractional Brownian motion при

\[
H\neq\frac12
\]

не является марковским процессом.

Поэтому continuation value может зависеть от всей наблюдаемой истории:

\[
\boxed{
C_t=f(X_{[0,t]}).
}
\]

То есть двух траекторий с одинаковым текущим значением \(X_t\), но разной историей, недостаточно считать эквивалентными.

Необходимо каким-либо способом кодировать историю процесса.

---

# 8. Что такое Signature

Signature — это математическое представление траектории через набор итерированных интегралов.

Для учета времени используется расширенный путь:

\[
\widehat X_t=(t,X_t).
\]

Signature имеет структуру

\[
\operatorname{Sig}(\widehat X)
=
(1,S^1,S^2,S^3,\ldots).
\]

Уровень 1 содержит интегралы первого порядка.

Уровень 2 — упорядоченные взаимодействия двух изменений.

Уровень 3 — взаимодействия трех изменений.

В общем случае

\[
S^k
\]

кодирует упорядоченные взаимодействия \(k\) изменений пути.

Например:

\[
\int dX,
\]

\[
\int dt\,dX,
\]

\[
\int dX\,dt,
\]

\[
\int dX\,dt\,dX,
\]

и т.д.

В практической реализации используется truncated signature:

\[
\boxed{
\operatorname{Sig}^{\le K}(X_{[0,t]}),
}
\]

то есть сохраняются только уровни до некоторого \(K\).

Главная интуиция:

```text
история траектории
        ↓
     Signature
        ↓
числовой вектор признаков
```

Теория signatures находится в **Section 2** статьи.

---

# 9. Почему Signature подходит для continuation value

Ключевое теоретическое основание находится в **Theorem 2.7 и Corollary 2.8** статьи.

Смысл результата состоит в том, что подходящие path-dependent функционалы могут быть приближены линейными функционалами от signature.

Схематично:

\[
f(X_{[0,t]})
\approx
\left\langle
\operatorname{Sig}^{\le K}(X_{[0,t]}),
\beta
\right\rangle.
\]

Поскольку continuation value имеет вид

\[
C_t=f(X_{[0,t]}),
\]

его можно аппроксимировать как

\[
\boxed{
C_t
\approx
\beta^\top
\operatorname{Sig}^{\le K}(X_{[0,t]}).
}
\]

Это теоретическое обоснование Signature Longstaff–Schwartz.

# 10. Monte Carlo и Signature Longstaff–Schwartz

Для фиксированных параметров

\[
(a,H)
\]

генерируется большое количество независимых fBm-траекторий:

\[
B_t^{H,(1)},\ldots,B_t^{H,(M)}.
\]

Для каждой строится процесс

\[
\boxed{
X_t^{(i)}
=
a t+B_t^{H,(i)}.
}
\]

После этого используется backward algorithm.

На последнем временном шаге:

\[
t_N=1
\]

остановка обязательна.

Затем алгоритм идет назад:

\[
t_{N-1},t_{N-2},\ldots,t_0.
\]

На каждом шаге:

1. берется история траектории \(X_{[0,t]}^{(i)}\);
2. считается signature;
3. по Monte Carlo trajectories обучается регрессия continuation value;
4. сравнивается текущий reward и continuation value;
5. принимается решение STOP или CONTINUE.

В линейном варианте:

\[
\hat C_t
=
\beta^\top
\operatorname{Sig}^{\le K}(X_{[0,t]}).
\]

Далее:

\[
Z_t\ge\hat C_t
\Rightarrow STOP,
\]

иначе:

\[
CONTINUE.
\]

Этот алгоритм описан в **Section 3.2 / Section 3.2.1** статьи.

---

# 11. Что такое stopping policy

После backward-обучения для фиксированной пары

\[
(a,H)
\]

получаем правило

\[
\boxed{
\pi_{a,H}(\text{история})
\rightarrow
\{STOP,\ CONTINUE\}.
}
\]

Это stopping policy.

При применении policy к конкретной тестовой траектории получается конкретный момент остановки

\[
\boxed{\tau^*}.
\]

То есть:

- policy — правило принятия решения;
- \(\tau^*\) — результат применения правила к конкретной траектории.

---

# 12. Оценка optimal stopping value

После обучения policy необходимо применять ее к независимым test Monte Carlo trajectories.

Для каждой траектории получаем

\[
\tau_i^*.
\]

Reward:

\[
Z_{\tau_i^*}^{(i)}
=
a\tau_i^*+
B_{\tau_i^*}^{H,(i)}.
\]

После усреднения:

\[
\boxed{
\hat V_{\text{primal}}(a,H)
=
\frac1M
\sum_{i=1}^{M}
\left(
a\tau_i^*
+
B_{\tau_i^*}^{H,(i)}
\right).
}
\]

Это оценка качества найденной stopping strategy и lower bound на истинное optimal stopping value.

В статье также реализован dual approach, позволяющий построить upper bound:

\[
\boxed{
V_{\text{primal}}
\le
V^*
\le
V_{\text{dual}}.
}
\]

Dual-часть находится в **Section 3.3** статьи.

# 14. Теоретическая часть: границы \(a_1(H)\) и \(a_2(H)\)

После добавления drift рассматриваем

\[
V(a,H)
=
\sup_\tau E[a\tau+B_\tau^H].
\]

Для каждого фиксированного \(H\) хотим найти две границы:

\[
\boxed{
a_1(H),\qquad a_2(H).
}
\]

Они разделяют три режима.

---

# 15. Нижняя граница \(a_1(H)\)

Если

\[
\tau=0,
\]

то

\[
Z_0=0.
\]

Следовательно,

\[
V(a,H)\ge0.
\]

При достаточно отрицательном drift оптимально остановиться сразу:

\[
\tau^*=0.
\]

Тогда

\[
V(a,H)=0.
\]

Естественное теоретическое определение:

\[
\boxed{
a_1(H)
=
\sup\{a:V(a,H)=0\}.
}
\]

Смысл:

> максимальный drift, при котором немедленная остановка все еще оптимальна.

---

# 16. Верхняя граница \(a_2(H)\)

Если всегда держать до конца:

\[
\tau=1.
\]

Тогда

\[
E[a+B_1^H]=a,
\]

так как

\[
E[B_1^H]=0.
\]

При достаточно большом положительном drift оптимально всегда держать до конца:

\[
\tau^*=1.
\]

Следовательно,

\[
V(a,H)=a.
\]

Естественное определение:

\[
\boxed{
a_2(H)
=
\inf\{a:V(a,H)=a\}.
}
\]

---

# 17. Три режима

Получаем:

\[
a\le a_1(H)
\Rightarrow
\tau^*=0,
\]

то есть оптимально не покупать / сразу остановиться.

Далее:

\[
a_1(H)<a<a_2(H)
\]

— нетривиальная optimal stopping область, где решение зависит от истории процесса.

И:

\[
a\ge a_2(H)
\Rightarrow
\tau^*=1,
\]

то есть оптимально купить и держать до конца.

---

# 18. Специальный случай \(H=1/2\)

При

\[
H=\frac12
\]

получаем обычное Brownian motion:

\[
X_t=at+W_t.
\]

Для bounded stopping time:

\[
E[W_\tau]=0.
\]

Следовательно:

\[
E[X_\tau]
=
aE[\tau].
\]

Если

\[
a<0,
\]

оптимально выбрать

\[
\tau=0.
\]

Если

\[
a>0,
\]

оптимально

\[
\tau=1.
\]

Поэтому:

\[
\boxed{
a_1(1/2)=a_2(1/2)=0.
}
\]

Это важный sanity check для теории и кода.

# 19. Что исследовать теоретически

Для функций

\[
a_1(H),a_2(H)
\]

можно исследовать:

- существование;
- единственность;
- соотношение \(a_1(H)\le a_2(H)\);
- непрерывность;
- монотонность;
- поведение около \(H=1/2\);
- предел при \(H\rightarrow1\);
- аналитические upper/lower bounds;
- ширину области нетривиального optimal timing:

\[
a_2(H)-a_1(H).
\]

Это основная новая теоретическая часть работы.

# 20. Численная оценка границ

Для фиксированного \(H\) перебираются различные значения \(a\).

Для каждой пары

\[
(a,H)
\]

обучается stopping policy и на независимых test trajectories получаются stopping times:

\[
\tau_1^*,\ldots,\tau_M^*.
\]

Считаются:

\[
\hat p_0(a,H)
=
\frac1M
\sum_i
1\{\tau_i^*=0\},
\]

и

\[
\hat p_1(a,H)
=
\frac1M
\sum_i
1\{\tau_i^*=1\}.
\]

Для нижней области ожидаем:

\[
P(\tau^*=0)\approx1
\]

и

\[
V(a,H)\approx0.
\]

Для верхней:

\[
P(\tau^*=1)\approx1
\]

и

\[
V(a,H)\approx a.
\]

Дополнительно можно использовать primal/dual bounds.

# 21. Уточнение границ

Сначала используется грубая сетка по \(a\).

Например:

\[
a=-3,-2.5,\ldots,3.
\]

После обнаружения интервала перехода можно применять bisection.

В результате получаем:

\[
\hat a_1(H),
\qquad
\hat a_2(H).
\]

Это повторяется для сетки значений \(H\):

\[
H=0.1,0.15,\ldots,0.9.
\]

После этого строятся функции

\[
H\mapsto a_1(H),
\]

\[
H\mapsto a_2(H).
\]

И численные результаты сравниваются с теоретическими свойствами.

```text

        ↓
оценка â, σ̂, Ĥ
        ↓
сравнение с истинными параметрами
```

Это позволит понять, насколько стабильно параметры вообще можно оценить на выбранном размере окна.

---

# 25. Нормировка реальных данных

После оценки:

\[
Y_t
\approx
\hat a t+\hat\sigma B_t^{\hat H}.
\]

Делим на \(\hat\sigma\):

\[
\tilde X_t
=
\frac{Y_t}{\hat\sigma}.
\]

Получаем:

\[
\boxed{
\tilde X_t
\approx
\frac{\hat a}{\hat\sigma}t+
B_t^{\hat H}.
}
\]

Вводим:

\[
\boxed{
\hat\mu
=
\frac{\hat a}{\hat\sigma}.
}
\]

То есть реальные данные приводятся к той же форме, что и синтетическая задача:

\[
\boxed{
X_t
=
\hat\mu t+B_t^{\hat H}.
}
\]

---

# 26. Теоретический прогноз для реального месяца

У нас уже получены функции:

\[
a_1(H),
\qquad
a_2(H).
\]

Для текущего месяца имеем:

\[
\hat\mu,\hat H.
\]

Сравниваем:

\[
\hat\mu
\]

с:

\[
a_1(\hat H),
\qquad
a_2(\hat H).
\]

Если

\[
\hat\mu\le a_1(\hat H),
\]

теория предсказывает:

```text
не покупать / STOP сразу
```

Если

\[
a_1(\hat H)<\hat\mu<a_2(\hat H),
\]

теория предсказывает:

```text
нетривиальный optimal timing
```

Если

\[
\hat\mu\ge a_2(\hat H),
\]

теория предсказывает:

```text
купить и держать до конца
```

---

# 27. Построение практической stopping model

Для оцененной пары

\[
(\hat\mu,\hat H)
\]

генерируются Monte Carlo trajectories:

\[
X_t^{(i)}
=
\hat\mu t+B_t^{\hat H,(i)}.
\]

На них рассчитываются signatures и обучается backward stopping model:

```text
synthetic trajectories
        ↓
Signatures
        ↓
Continuation Value
        ↓
STOP / CONTINUE policy
```

Модель можно:

1. обучать заново каждый месяц;
2. либо заранее построить библиотеку policies на сетке \((a,H)\).

Второй вариант может быть вычислительно более удобным.

---

# 28. Применение к следующему реальному месяцу

В начале месяца наблюдается:

\[
S_0.
\]

Далее появляются реальные цены:

\[
S_1,S_2,\ldots
\]

В каждый момент строится нормированный путь:

\[
\boxed{
\tilde X_t
=
\frac{\ln(S_t/S_0)}{\hat\sigma}.
}
\]

Для наблюдаемой истории:

\[
\tilde X_{[0,t]}
\]

считается signature:

\[
\operatorname{Sig}(\tilde X_{[0,t]}).
\]

Далее:

\[
\operatorname{Sig}
\rightarrow
\hat C_t
\rightarrow
STOP/CONTINUE.
\]

Когда модель впервые выбирает STOP, получаем:

\[
\boxed{\tau^*}.
\]

Это и есть практический момент продажи.

---

# 29. Walk-forward backtest

Процесс повторяется для большого количества месяцев:

```text
история → параметры → январь → τ*
история → параметры → февраль → τ*
история → параметры → март → τ*
...
```

Для каждого нового месяца параметры оцениваются заново:

\[
\hat a_t,
\quad
\hat\sigma_t,
\quad
\hat H_t.
\]

Таким образом получается out-of-sample backtest без использования будущей информации.

# 30. Сравнение трех подходов

В финале сравниваются:

## 30.1. Теоретический режим

По значениям

\[
\hat\mu,\hat H
\]

и границам

\[
a_1(\hat H),a_2(\hat H)
\]

получаем:

```text
STOP / TIMING / HOLD
```

## 30.2. Signature Optimal Stopping

Модель выбирает конкретный момент:

\[
\tau^*.
\]

Доходность стратегии:

\[
R_{\text{Sig}}
=
\frac{S_{\tau^*}}{S_0}-1.
\]

## 30.3. Buy-and-Hold

Купили в начале месяца и продали в конце:

\[
\boxed{
R_{\text{BH}}
=
\frac{S_T}{S_0}-1.
}
\]

# 31. Метрики практического сравнения

Можно использовать:

- cumulative return;
- среднюю месячную доходность;
- volatility;
- Sharpe ratio;
- maximum drawdown;
- долю прибыльных месяцев;
- распределение stopping times;
- средний момент продажи \(E[\tau^*]\).

Особенно полезно проверить, действительно ли strategy регулярно использует early stopping или в реальных данных практически всегда превращается в Buy-and-Hold.
