## 7.1. Что даёт статья и репозиторий

```text
Optimal Stopping + Signatures + fBm + Primal/Dual methods
```

Репозиторий авторов предоставляет рабочую реализацию базовой задачи

$$
\sup_\tau E[B^H_\tau].
$$

---

## 7.2. Что добавляет магистерская

1. **Drift в постановке:** $B^H_t \rightarrow \mu t + B^H_t$, задача $V(\mu,H)=\sup_\tau E[\mu\tau+B^H_\tau]$.
2. **Теоретическое исследование границ** $\mu_1(H),\mu_2(H)$: корректность определений (выпуклость $V$ по $\mu$, лучевая структура множеств режимов, $\mu_1\le\mu_2$), опорный случай $H=1/2$, скейлинг по горизонту, свойства кривых.
3. **Численная проверка границ** на сетке $(\mu,H)$ тремя независимыми критериями с primal/dual контролем качества.
4. **Оценка $a,\sigma,H$** по реальным данным с честным измерением дисперсии оценок.
5. **Перенос stopping strategy на S&P 500** с корректным пересчётом единиц времени.
6. **Out-of-sample сравнение** с Buy-and-Hold и наивным таймингом, с оценкой статистической значимости.

Содержательный центр новизны — пункт 2: **функции $\mu_1(H),\mu_2(H)$ и ширина $\Delta(H)=\mu_2-\mu_1$ как количественная мера ценности тайминга, порождённой памятью процесса.** Всё остальное — либо метод статьи, либо его применение.

## 7.3. Полная цепочка работы

```text
S_t = S_0 exp(a t + σ B_t^H)
        ↓ log + нормировка
X_t = μ t + B_t^H,   μ = a/σ
        ↓
V(μ,H) = sup E[μτ + B_τ^H]
        ↓ fBm немарковский, имеет память
Signature кодирует историю
        ↓ Snell / Bellman
Continuation Value → STOP / CONTINUE
        ↓ Monte Carlo + backward (Longstaff–Schwartz)
τ* и оценки V (primal ≤ V* ≤ dual)
        ↓ перебор сетки (μ, H) + bisection
μ_1(H), μ_2(H), Δ(H)
        ↓ теория vs численная проверка
        ↓ S&P 500 history
â, σ̂, Ĥ  →  μ̂ = (â/σ̂)·N^(1−Ĥ)
        ↓ сравнение μ̂ с μ_1(Ĥ), μ_2(Ĥ)
теоретический режим месяца
        ↓ Signature policy на следующем месяце
реальный τ*
        ↓
Theory vs Signature vs Buy-and-Hold
```

## 7.4. ➕ Дополнение: этапы и чек-лист

Порядок важен: каждый этап опирается на пройденную валидацию предыдущего.

**Этап 0 — воспроизведение.**
- [ ] запустить `Notebooks/Example_Optimal_Stopping_FBM.ipynb` из репозитория авторов;
- [ ] воспроизвести числа из Section 4.1 статьи для $\mu=0$.

**Этап 1 — drift в коде.**
- [ ] заменить reward на $X_t=\mu t + B^H_t$;
- [ ] проверки 1–4 из [04.5](04-numerics.md#45-валидация-и-sanity-checks) (особенно $H=1/2$);
- [ ] обвязка: конфиг, seed, сохранение результатов.

**Этап 2 — теория.**
- [ ] Лемма о выпуклости и следствия ([02.3](02-theory-boundaries.md#23--дополнение-корректность-определений-выпуклость));
- [ ] случай $H=1/2$;
- [ ] закон скейлинга по $T$;
- [ ] попытки: непрерывность, монотонность, аналитические оценки, поведение $\Delta(H)$.

**Этап 3 — численные границы.**
- [ ] грубая сетка по $\mu$ при нескольких $H$;
- [ ] bisection с контролем MC-ошибки;
- [ ] полная сетка $H$, кривые $\mu_1,\mu_2,\Delta$;
- [ ] проверки устойчивости по $K$, $M$, $N$;
- [ ] сопоставление с теоретическими предсказаниями Этапа 2.

**Этап 4 — оценивание параметров.**
- [ ] выбор оценщиков $a,\sigma,H$;
- [ ] калибровка на синтетике: смещение и **дисперсия** $\hat\mu$ по длинам окна;
- [ ] решение про длины окон.

**Этап 5 — эмпирика.**
- [ ] загрузка и подготовка данных S&P 500;
- [ ] walk-forward: помесячные $(\hat\mu,\hat H)$, режимы, $\tau^{\ast}$;
- [ ] распределение месяцев по режимам;
- [ ] метрики и сравнение с бенчмарками, доверительные интервалы.

**Этап 6 — оформление.**
- [ ] раздел рисков и ограничений ([06.5](06-evaluation.md#65--дополнение-риски-и-ограничения-работы));
- [ ] воспроизводимость: конфиги, seed, версии, скрипты генерации всех графиков.

## 7.5. Минимальная защищаемая версия

Если времени не хватит, работа остаётся полноценной при выполнении Этапов 0–3 плюс сокращённого Этапа 5: теоретическое и численное описание границ $\mu_1(H),\mu_2(H)$ — самостоятельный результат, а эмпирическая часть может быть представлена как иллюстрация применимости. Обратный порядок (эмпирика без валидированных границ) не даёт защищаемого результата.
